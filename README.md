DESCRIPTION
========================================
This is a simple game created in about an hour for jumpstart haven! It's a simple bubble collecting game with an open world with boundaries.
The goal is to collect 20 bubbles before the time limit of 1 minute is up! It's got an isometric tile design as well an old fist animation for the player!

Tech Stack
========================================

⭐️*Itch.io* - for the deployment
